## Projeto em Destaque

### 🔐 [Safe Talk - Chat Criptografado](https://github.com/rjuulia)
> **Projeto de TCC** | Sistema de comunicação segura para escritórios de advocacia

Plataforma de chat com **criptografia ponta a ponta (E2EE)** desenvolvida para garantir comunicação confidencial entre advogados e clientes.

#### Principais Características:
- **Criptografia Híbrida**: RSA-OAEP (2048 bits) + AES-GCM (256 bits)
- **Assinatura Digital**: RSA-PSS para autenticidade de mensagens
- **Verificação de Integridade**: Hash SHA-256
- **Anexos Seguros**: Upload de documentos com criptografia
- **Auto-destruição**: Mensagens expiram após 15 dias (LGPD compliant)
- **Gestão de Usuários**: Sistema de papéis (cliente/advogado/admin)

#### Stack Tecnológica:
**Backend:**
- Python 3.10 | FastAPI (Railway)
- PostgreSQL (Supabase)
- SQLAlchemy
- JWT + Bcrypt
- Web Crypto API

**Frontend:**
- HTML5 | CSS3 | JavaScript (ES6+)
- Responsive Design (Vercel)


> **Objetivo**: Garantir privacidade total nas comunicações jurídicas, onde nem o servidor pode ler as mensagens.
