## 🚀 Featured Project

### 🔐 [Safe Talk - Encrypted Chat](https://github.com/rjuulia)
> **Capstone Project** | Secure communication system for law firms

Chat platform with **end-to-end encryption (E2EE)** developed to ensure confidential communication between lawyers and clients.

#### ⚡ Key Features:
- 🔒 **Hybrid Encryption**: RSA-OAEP (2048 bits) + AES-GCM (256 bits)
- ✍️ **Digital Signature**: RSA-PSS for message authenticity
- 🔍 **Integrity Verification**: SHA-256 Hash
- 📎 **Secure Attachments**: Encrypted file uploads
- 🗑️ **Auto-destruction**: Messages expire after 15 days (LGPD compliant)
- 👥 **User Management**: Role-based system (client/lawyer/admin)

#### 🛠️ Tech Stack:
**Backend:**
- Python 3.10 | FastAPI
- PostgreSQL (Supabase)
- SQLAlchemy
- JWT + Bcrypt
- Web Crypto API

**Frontend:**
- HTML5 | CSS3 | JavaScript (ES6+)
- Responsive Design
- Vanilla JS (no frameworks)

**Infrastructure:**
- Docker
- Railway (Backend)
- Vercel (Frontend)
- Supabase (Database + Storage)

#### 🔐 Security Architecture:
```
Client → Generates AES Key → Encrypts Message → Signs Hash
         ↓
   Encrypts AES Key with RSA (for each participant)
         ↓
   Sends to Server → Stores encrypted → PostgreSQL
```

> 🎯 **Goal**: Ensure complete privacy in legal communications, where even the server cannot read messages.
